Adventure guide

How to write a CYOA JSON

Expected structure

An adventure contains metadata, a starting location, and a list of connected locations.

{
    "id": "forest-adventure",
    "description": "Find your way through the forest.",
    "startLocationId": "entrance",
    "locations": [
        {
            "id": "entrance",
            "text": "You stand at the forest entrance.",
            "options": [
                {
                    "text": "Enter the forest",
                    "locationId": "clearing"
                }
            ]
        },
        {
            "id": "clearing",
            "text": "You reach a quiet clearing."
        }
    ]
}

Required fields

  • id: A unique ID for the adventure.
  • description: A short description of the adventure.
  • startLocationId: The ID of the first location.
  • locations: At least one location with a unique ID and text.
  • options: Optional choices with text and a target location ID.

Connect and finish the story

Every option's locationId must match an existing location. A location with no options is an ending. After saving the JSON file, return to the upload page and upload it to play.
